## 阶段 1：内容驱动（让平台有东西可玩）

> **目标**：手动录入几场真实比赛，平台不再空荡荡  
> **时间**：1-2 天

- [ ] 录入 VCT CN 联赛当前赛季至少 8 支队伍 + 5 场比赛
- [ ] 写一个 SQL 脚本批量导入，不用手动一条条录
- [ ] 管理后台增加「批量导入赛事」功能（粘贴 JSON/CSV）
- [ ] 首页增加「热门赛事」推荐位
- [ ] 找 2-3 个同学注册测试，收集反馈

---

## 阶段 2：体验打磨（让人愿意留下来）

> **目标**：修掉所有粗糙的地方，体验像正式产品  
> **时间**：1-2 周

### 2.1 押注体验
- [ ] 押注后弹出确认动画（猜中绿色烟花 / 猜错红色提示）
- [ ] 比赛开始前 5 分钟截止押注（倒计时显示）
- [ ] 押注历史增加「收益曲线」— 积分随时间变化图
- [ ] 支持修改押注（比赛开始前可以改）

### 2.2 通知系统
- [ ] 比赛即将开始时浏览器通知
- [ ] 结算完成后通知「你猜中了！+50积分」
- [ ] 被排行榜超越时通知

### 2.3 移动端
- [ ] 响应式布局（手机上看赛事列表和排行榜不崩）
- [ ] 赛事卡片在手机上改为纵向排列
- [ ] 押注面板手机端全屏弹窗

### 2.4 细节
- [ ] 密码修改功能
- [ ] 找回密码（邮箱验证码）
- [ ] 注册增加邮箱字段
- [ ] 首页增加公告栏

---

## 阶段 3：多游戏 + 玩法升级

> **目标**：不只瓦，支持 CS2/Dota2/LOL 多游戏  
> **时间**：2-3 周

### 3.1 多游戏
- [ ] 游戏管理页面（管理后台增加/启停游戏）
- [ ] 首页顶部游戏切换 Tab
- [ ] 每种游戏独立排行榜
- [ ] 游戏图标 + 描述

### 3.2 玩法
- [ ] BO3/BO5 系列赛支持（一场比赛拆多局）
- [ ] 特殊竞猜：首杀队伍、总回合数、MVP 选手
- [ ] 竞猜房间：创建私密房间，邀请好友 PK 猜中率
- [ ] 每日签到领积分

### 3.3 社交
- [ ] 赛事评论区（每场比赛一个讨论区）
- [ ] 关注好友，看他们押了什么
- [ ] 押注分享卡片（生成图片一键分享）

---

## 阶段 4：自动化

> **目标**：不用手动录比赛了  
> **时间**：2-3 周

- [ ] 爬虫抓取 VLR.gg 公开赛程（定时任务）
- [ ] 自动同步赛程到数据库
- [ ] 比赛结果自动结算（根据赛程 API 结果）
- [ ] 异常处理：爬虫失败告警、手动兜底

---

## 阶段 5：安全加固

> **目标**：能扛住真实用户量  
> **时间**：1-2 周

- [ ] 登录失败限制（5 次锁 15 分钟）
- [ ] 押注接口幂等性（防重复提交）
- [ ] SQL 注入防护检查
- [ ] XSS 防护（前端输入过滤）
- [ ] 接口限流（防刷分）
- [ ] 操作日志记录
- [ ] HTTPS 证书配置

---
