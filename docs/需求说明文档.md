## 1. 引言

### 1.1 项目背景

随着电子竞技产业的快速发展，以《无畏契约》（VALORANT）为代表的 FPS 电竞项目在全球范围内拥有大量观众。然而，国内缺少一个面向普通玩家的、非盈利性质的赛事竞猜平台。本项目旨在填补这一空白，为电竞爱好者提供一个轻量级的赛事信息查询与趣味竞猜平台。

### 1.2 项目目标

- 提供一个实时更新的电竞赛事信息展示平台
- 支持用户通过虚拟积分参与赛事结果竞猜
- 通过排行榜机制激发用户参与积极性
- 管理员可便捷管理赛事数据和执行结算操作

### 1.3 适用范围

本系统面向无畏契约（VALORANT）电竞观众，覆盖 VCT CN、VCT Americas、VCT EMEA、VCT Pacific、Masters、Champions 六大联赛。

## 2. 用户角色分析

| 角色 | 标识 | 权限概述 |
|------|------|----------|
| **普通用户** | role=0 | 注册登录、查看赛事、下注竞猜、查看排行榜、管理个人资料 |
| **管理员** | role=1 | 包含普通用户全部权限 + 赛事创建/编辑/删除、批量导入、手动结算、数据同步 |

### 2.1 普通用户用例

- 注册账号（用户名、密码、昵称）
- 登录系统（JWT 令牌认证，7天有效期）
- 查看赛事列表（支持按状态筛选、分页）
- 查看赛事详情（队伍信息、比分、联赛归属）
- 对未开始/进行中的赛事下注
- 查看个人下注历史（含盈亏计算）
- 查看排行榜（积分榜 Top N、我的排名）
- 修改个人资料（昵称、头像）
- 查看其他用户公开主页

### 2.2 管理员用例

- 包含普通用户全部功能
- 创建新赛事（手动录入）
- 编辑已有赛事信息
- 批量导入赛事数据
- 执行赛事结果结算（释放积分）
- 触发 Riot API 数据同步
- 查看管理后台仪表盘

## 3. 功能需求

### 3.1 用户模块

#### 3.1.1 注册 (FR-USER-001)

| 项目 | 描述 |
|------|------|
| **功能描述** | 新用户通过用户名、密码、昵称注册账号 |
| **输入** | username（3-20字符）、password（6-30字符）、nickname（可选，默认同用户名） |
| **输出** | 注册成功返回用户信息（不含密码） |
| **业务规则** | 用户名唯一；密码 BCrypt 加密存储；新用户初始积分 1000 |
| **异常处理** | 用户名已存在 → "用户名已存在"；参数无效 → 对应提示 |

#### 3.1.2 登录 (FR-USER-002)

| 项目 | 描述 |
|------|------|
| **功能描述** | 已注册用户通过用户名和密码登录 |
| **输入** | username、password |
| **输出** | JWT token + 用户信息（不含密码） |
| **业务规则** | 密码 BCrypt 校验；Token 有效期 7 天；Token 含 userId、username、role |
| **异常处理** | 用户名或密码错误 → "用户名或密码错误" |

#### 3.1.3 个人中心 (FR-USER-003)

| 项目 | 描述 |
|------|------|
| **功能描述** | 登录用户查看和修改个人信息 |
| **包含** | 查看个人资料、修改昵称、上传头像（支持 jpg/png/gif/webp，≤2MB） |

#### 3.1.4 公开主页 (FR-USER-004)

| 项目 | 描述 |
|------|------|
| **功能描述** | 查看任意用户的公开信息 |
| **展示内容** | 昵称、头像、积分、连胜、猜中率、押注总数 |

### 3.2 赛事模块

#### 3.2.1 赛事列表 (FR-MATCH-001)

| 项目 | 描述 |
|------|------|
| **功能描述** | 分页展示赛事，支持按状态筛选（未开始/进行中/已结束） |
| **排序规则** | 未开始按时间升序，已结束按时间降序 |
| **展示字段** | 标题、队伍A/B、Logo、联赛、比赛时间、状态、比分 |

#### 3.2.2 赛事详情 (FR-MATCH-002)

| 项目 | 描述 |
|------|------|
| **功能描述** | 查看单场赛事详细信息，含当前下注统计 |
| **展示字段** | 完整赛事信息 + 下注人数 |

#### 3.2.3 联赛分组浏览 (FR-MATCH-003)

| 项目 | 描述 |
|------|------|
| **功能描述** | 按联赛分组展示全部赛事 |
| **分组方式** | 以 tournament 字段为 key，同一联赛赛事归入一组 |

#### 3.2.4 热门赛事 (FR-MATCH-004)

| 项目 | 描述 |
|------|------|
| **功能描述** | 首页展示即将开始和进行中的赛事，最多 6 条 |

#### 3.2.5 赛事管理（管理员）(FR-MATCH-005)

| 功能 | 描述 |
|------|------|
| 创建赛事 | 手动录入单个赛事（标题、队伍A/B、Logo、联赛、比赛时间） |
| 编辑赛事 | 修改已有赛事信息 |
| 批量导入 | 一次性导入多条赛事 JSON 数据，返回成功/失败统计 |
| 结算赛事 | 对已结束赛事执行结果结算，联动处理所有相关押注 |
| 数据同步 | 从 Riot Esports API 同步最新赛事数据 |

### 3.3 押注模块

#### 3.3.1 下注 (FR-BET-001)

| 项目 | 描述 |
|------|------|
| **功能描述** | 用户对未结束的赛事进行押注 |
| **输入** | matchId、betSide（0=A胜/1=B胜）、betAmount |
| **业务规则** | 赛事状态必须为未开始(0)或进行中(1)；同一赛事不可重复下注；下注金额必须 > 0 且 ≤ 用户当前积分；扣除积分采用乐观锁（积分 ≥ betAmount 才扣减） |
| **异常处理** | 积分不足 → "积分不足"；重复下注 → "您已对该赛事下注" |

#### 3.3.2 下注历史 (FR-BET-002)

| 项目 | 描述 |
|------|------|
| **功能描述** | 查看个人下注记录（含赛事信息和盈亏计算） |
| **展示字段** | 赛事标题、队伍A/B、押注方、押注金额、返还金额、净盈亏、状态 |
| **盈亏计算** | 猜中：betAmount × 2；平局：退还 betAmount；未中：0 |

#### 3.3.3 近期战绩 (FR-BET-003)

| 项目 | 描述 |
|------|------|
| **功能描述** | 查看最近 10 条下注记录（含赛事信息） |

#### 3.3.4 自动结算 (FR-BET-004)

| 项目 | 描述 |
|------|------|
| **功能描述** | 赛事结算时自动处理所有关联押注 |
| **结算规则** | 猜中：返还 betAmount × 2，correctBets+1，winStreak+1；平局：退还 betAmount；未中：积分不返还，winStreak 重置为 0 |

### 3.4 排行榜模块

#### 3.4.1 积分榜 (FR-LEADER-001)

| 项目 | 描述 |
|------|------|
| **功能描述** | 按积分降序展示用户排名，支持分页 |
| **展示字段** | 排名、昵称、头像、积分、猜中率、总押注数、连胜 |

#### 3.4.2 Top N (FR-LEADER-002)

| 项目 | 描述 |
|------|------|
| **功能描述** | 获取积分前 N 名用户 |

#### 3.4.3 我的排名 (FR-LEADER-003)

| 项目 | 描述 |
|------|------|
| **功能描述** | 登录用户查看自己在全服中的排名 |

### 3.5 数据同步模块

#### 3.5.1 Riot API 自动同步 (FR-SYNC-001)

| 项目 | 描述 |
|------|------|
| **功能描述** | 从 Riot Esports API 自动拉取 6 个联赛的赛事数据 |
| **同步方式** | 管理员手动触发 + 定时任务自动执行 |
| **同步逻辑** | 以 externalId 去重；已存在则更新（状态、比分、结果），首次获得结果时自动联动结算；不存在则新增 |
| **过滤规则** | 仅同步 2026-01-01 之后的赛事 |

## 5. 非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 接口响应时间 | 普通查询 < 500ms，复杂查询 < 2s |
| 并发支持 | 满足课程展示场景，单机 50+ 并发 |
| 数据同步 | 定时任务异步执行，不阻塞主流程 |

### 5.2 安全要求

| 项目 | 实现方式 |
|------|----------|
| 密码存储 | BCrypt 单向加密 |
| 身份认证 | JWT 令牌，7天过期 |
| 权限控制 | 拦截器 + 角色校验（role=1 为管理员） |
| 积分安全 | 乐观锁更新积分，防止负数 |
| 接口防刷 | 同一赛事不可重复下注 |
| SQL 注入 | MyBatis-Plus 参数化查询 |

### 5.3 可用性要求

- 前端采用暗黑电竞风格 UI，视觉统一
- 响应式布局，适配不同屏幕尺寸
- 登录过期自动跳转登录页
- 网络异常/服务器错误有明确提示（Element UI Message）

### 5.4 可维护性要求

- 代码分层清晰：controller → service → mapper
- 统一响应格式 `Result<T>`（code + message + data）
- 统一异常处理 `GlobalExceptionHandler`
- 数据库脚本完整，支持一键初始化
