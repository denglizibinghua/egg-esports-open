## 1. 系统架构设计

### 1.1 技术选型

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **后端框架** | Spring Boot | 3.0.6 | Java 17 |
| **ORM** | MyBatis-Plus | 3.5.3.1 | 简化 CRUD，Lambda 查询 |
| **数据库** | MySQL | 8.0 | InnoDB 引擎，utf8mb4 |
| **认证** | JJWT | 0.11.5 | JWT 令牌，HS256 签名 |
| **密码加密** | Spring Security Crypto | - | BCrypt 单向加密 |
| **前端框架** | Vue | 2.x | SPA 单页应用 |
| **UI 组件** | Element UI | - | 暗黑电竞风格 |
| **HTTP 客户端** | Axios | - | 拦截器统一处理 token |
| **路由** | Vue Router | - | History 模式，权限守卫 |
| **外部 API** | Riot Esports API | - | 赛事数据同步（6个联赛） |

### 2.1 ER 图

```
┌──────────────┐        ┌──────────────────┐        ┌──────────────┐
│   egg_game   │        │    egg_match      │        │   egg_bet    │
├──────────────┤        ├──────────────────┤        ├──────────────┤
│ id (PK)      │◀──┐    │ id (PK)           │◀──┐    │ id (PK)      │
│ name         │   │    │ game_id (FK)      │   │    │ user_id (FK) │──┐
│ icon         │   └────│ external_id       │   └────│ match_id(FK) │  │
│ sort_order   │        │ title             │        │ bet_side     │  │
│ status       │        │ team_a            │        │ bet_amount   │  │
│ create_time  │        │ team_b            │        │ status       │  │
└──────────────┘        │ team_a_logo       │        │ create_time  │  │
                         │ team_b_logo       │        └──────────────┘  │
                         │ tournament        │                          │
                         │ match_time        │        ┌──────────────┐  │
                         │ score_a           │        │   egg_user   │  │
                         │ score_b           │        ├──────────────┤  │
                         │ status            │        │ id (PK)      │◀─┘
                         │ result            │        │ username     │
                         │ create_time       │        │ password     │
                         └──────────────────┘        │ nickname     │
                                                      │ avatar       │
                                                      │ points       │
                                                      │ total_bets   │
                                                      │ correct_bets │
                                                      │ win_streak   │
                                                      │ max_win_streak│
                                                      │ role         │
                                                      │ create_time  │
                                                      └──────────────┘

关系说明：
  egg_game 1 ─── N egg_match    (一个游戏有多个赛事)
  egg_user 1 ─── N egg_bet      (一个用户有多条下注)

```

### 2.2 表结构设计

#### 2.2.1 egg_game（游戏表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 游戏ID |
| name | VARCHAR(50) | NOT NULL | 游戏名称 |
| icon | VARCHAR(255) | DEFAULT '' | 图标URL |
| sort_order | INT | DEFAULT 0 | 排序 |
| status | TINYINT | DEFAULT 1 | 0=停用, 1=启用 |
| create_time | DATETIME | DEFAULT NOW() | 创建时间 |

#### 2.2.2 egg_user（用户表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 用户ID |
| username | VARCHAR(50) | NOT NULL, UNIQUE(索引) | 用户名 |
| password | VARCHAR(255) | NOT NULL | 密码（BCrypt） |
| nickname | VARCHAR(50) | DEFAULT '' | 昵称 |
| avatar | VARCHAR(255) | DEFAULT '' | 头像URL |
| points | INT | DEFAULT 1000 | 积分 |
| total_bets | INT | DEFAULT 0 | 总押注次数 |
| correct_bets | INT | DEFAULT 0 | 猜中次数 |
| win_streak | INT | DEFAULT 0 | 当前连胜 |
| max_win_streak | INT | DEFAULT 0 | 历史最大连胜 |
| role | TINYINT | DEFAULT 0 | 0=普通用户, 1=管理员 |
| create_time | DATETIME | DEFAULT NOW() | 注册时间 |

#### 2.2.3 egg_match（赛事表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 赛事ID |
| external_id | VARCHAR(64) | - | Riot API 赛事ID（去重用） |
| game_id | BIGINT | NOT NULL, FK→egg_game | 游戏ID |
| title | VARCHAR(200) | NOT NULL | 赛事标题 |
| team_a | VARCHAR(100) | NOT NULL | A队名称 |
| team_b | VARCHAR(100) | NOT NULL | B队名称 |
| team_a_logo | VARCHAR(255) | DEFAULT '' | A队Logo |
| team_b_logo | VARCHAR(255) | DEFAULT '' | B队Logo |
| tournament | VARCHAR(100) | DEFAULT '' | 联赛/杯赛名称 |
| match_time | DATETIME | NOT NULL | 比赛时间 |
| score_a | INT | - | A队比分 |
| score_b | INT | - | B队比分 |
| status | TINYINT | DEFAULT 0 | 0=未开始, 1=进行中, 2=已结束 |
| result | TINYINT | DEFAULT NULL | NULL=未结算, 0=A胜, 1=B胜, 2=平局 |
| create_time | DATETIME | DEFAULT NOW() | 创建时间 |

#### 2.2.4 egg_bet（押注表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 押注ID |
| user_id | BIGINT | NOT NULL, FK→egg_user | 用户ID |
| match_id | BIGINT | NOT NULL, FK→egg_match | 赛事ID |
| bet_side | TINYINT | NOT NULL | 0=押A队胜, 1=押B队胜 |
| bet_amount | INT | NOT NULL | 押注积分 |
| status | TINYINT | DEFAULT 0 | 0=待结算, 1=猜中, 2=未中 |
| create_time | DATETIME | DEFAULT NOW() | 押注时间 |

#### 2.2.5 索引设计

```sql
-- egg_user
CREATE INDEX idx_user_username ON egg_user(username);

-- egg_match
CREATE INDEX idx_match_game_id ON egg_match(game_id);
CREATE INDEX idx_match_status ON egg_match(status);
CREATE INDEX idx_match_time ON egg_match(match_time);

-- egg_bet
CREATE INDEX idx_bet_user_id ON egg_bet(user_id);
CREATE INDEX idx_bet_match_id ON egg_bet(match_id);
CREATE INDEX idx_bet_user_match ON egg_bet(user_id, match_id);  -- 复合索引，防重复下注
```

## 3. 接口设计

### 3.1 通用约定

| 项目 | 约定 |
|------|------|
| Base URL | `/api` |
| 认证方式 | Header: `Authorization: Bearer <token>` |
| 响应格式 | `{ "code": 200, "message": "操作成功", "data": ... }` |
| 错误码 | 200=成功, 401=未登录, 403=无权限, 500=服务器错误 |
| Content-Type | `application/json;charset=UTF-8` |

### 3.2 用户模块接口（/api/user）

| 方法 | 路径 | 认证 | 角色 | 说明 | 请求体/参数 | 响应 data |
|------|------|------|------|------|-------------|-----------|
| POST | /register | ✗ | - | 注册 | `{username, password, nickname?}` | EggUser |
| POST | /login | ✗ | - | 登录 | `{username, password}` | `{token, user}` |
| GET | /me | ✓ | user | 当前用户信息 | - | EggUser |
| GET | /{id} | ✗ | - | 用户公开信息 | path: id | `{id,nickname,avatar,points,...}` |
| PUT | /profile | ✓ | user | 修改昵称 | `{nickname}` | EggUser |
| POST | /avatar | ✓ | user | 上传头像 | form-data: file | `{avatar}` |

### 3.3 赛事模块接口（/api/match）

| 方法 | 路径 | 认证 | 角色 | 说明 | 请求体/参数 | 响应 data |
|------|------|------|------|------|-------------|-----------|
| GET | /tournaments | ✗ | - | 按联赛分组赛事 | - | `Map<联赛名, List<Match>>` |
| GET | /list | ✗ | - | 赛事列表（分页） | `?status=&page=1&size=10` | `IPage<Match>` |
| GET | /{id} | ✗ | - | 赛事详情 | path: id | EggMatch |
| GET | /hot | ✗ | - | 热门赛事 | `?limit=6` | `List<Match>` |
| POST | /create | ✓ | admin | 创建赛事 | `{title,teamA,teamB,...}` | EggMatch |
| PUT | /update | ✓ | admin | 更新赛事 | `{id,title?,teamA?,...}` | EggMatch |
| PUT | /settle | ✓ | admin | 结算赛事 | `{matchId, result}` | EggMatch |
| POST | /batch-import | ✓ | admin | 批量导入 | `[{...}, {...}]` | `{success,fail,total,errors}` |
| POST | /sync | ✓ | admin | 触发 Riot 同步 | - | SyncResult |

### 3.4 押注模块接口（/api/bet）

| 方法 | 路径 | 认证 | 角色 | 说明 | 请求体/参数 | 响应 data |
|------|------|------|------|------|-------------|-----------|
| POST | /place | ✓ | user | 下注 | `{matchId, betSide, betAmount}` | EggBet |
| GET | /my | ✓ | user | 我的下注（含盈亏） | `?status=` | `List<BetHistoryVO>` |
| GET | /settled-since | ✓ | user | 指定时间后已结算下注 | `?since=ISO_TIME` | `List<BetHistoryVO>` |
| GET | /count/{matchId} | ✗ | - | 赛事下注数 | path: matchId | Long |
| GET | /recent | ✓ | user | 近期战绩(10条) | - | `List<Map>` |

### 3.5 排行榜模块接口（/api/leaderboard）

| 方法 | 路径 | 认证 | 角色 | 说明 | 请求体/参数 | 响应 data |
|------|------|------|------|------|-------------|-----------|
| GET | /points | ✗ | - | 积分榜（分页） | `?page=1&size=20` | `Page<LeaderboardVO>` |
| GET | /top/{n} | ✗ | - | Top N | path: n | `List<LeaderboardVO>` |
| GET | /my-rank | ✓ | user | 我的排名 | - | `{rank, total}` |

```
EggMatchService ──────▶ EggBetService
      │                      │
      ▼                      ▼
```

## 6. 安全设计

### 6.1 认证流程

```
1. 用户登录 → 后端验证密码(BCrypt) → 签发 JWT Token
2. Token 结构: Header.Payload.Signature
   Payload: { sub: userId, username, role, iat, exp }
3. 客户端存储: localStorage (egg_token, egg_user)
4. 每次请求: Authorization: Bearer <token>
5. 拦截器: 校验 token 有效性 → 解析 userId/role → 注入 request attribute
```

### 6.2 权限模型

| 路径前缀 | 权限要求 | 实现方式 |
|----------|----------|----------|
| /api/user/login | 无 | excludePathPatterns |
| /api/user/register | 无 | excludePathPatterns |
| /api/user/me, /profile, /avatar | 已登录 | 拦截器校验 token |
| /api/bet/place, /my, /recent | 已登录 | 拦截器校验 token |
| /api/match/create, update, settle, batch-import, sync | 管理员(role=1) | 拦截器内路径白名单校验 |
| 其他 /api/** | 已登录 + token 有效 | 拦截器校验 token |
| /api/match/list, /{id}, /hot, /tournaments | 公开 | 不需要 admin，拦截器内不拦截该路径 |
| /api/leaderboard/** | 公开 | 不需要 admin |

### 6.3 安全措施

| 措施 | 实现 |
|------|------|
| 密码加密 | BCrypt (spring-security-crypto) |
| Token 过期 | JWT 7天过期，过期后前端自动跳转登录 |
| 积分安全 | 乐观锁 `WHERE points >= betAmount`，`GREATEST(0, points + delta)` |
| 防重复下注 | 数据库唯一复合索引 `idx_bet_user_match(user_id, match_id)` |
| SQL 注入防护 | MyBatis-Plus 参数化查询，不使用字符串拼接 |
| CORS | 允许所有来源（开发阶段），生产环境应限制域名 |
| 错误信息脱敏 | 登录失败统一返回"用户名或密码错误"，不区分用户不存在/密码错误 |
