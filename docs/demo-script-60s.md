# 60s 演示录屏脚本 · Egg Esports 演示站

> 定位：小甲方 3 秒看懂“3天可交付同款瓦洛兰特预测社区”  
> 演示站：https://eggesports.com  
> 演示账号：`demo_player / demo123`（押注）· `demo_admin / demo123`（管理/灌数据）  
> 录屏分辨率：1280×720，Chrome 无痕 + 书签栏隐藏，光标放大  
> 口播基调：沉稳、数字说话，不提网吧/年费/299，不提菠菜/变现

## 分镜动线（严格按秒）

### 0–3s · Hero 一行讲清价值
- **画面**：`/` 首屏静止 1s → 缓慢放大 Hero 标题+副标题
- **对准**：`瓦洛兰特预测社区` + `已服务 32 场校园赛 · 0%抽水纯彩池 · 3天可交付同款` + 「立即竞猜」CTA
- **口播**（3s）：“瓦洛兰特预测社区，32 场已交付，0%抽水纯彩池，3天可交付同款。”
- **字幕**：`#瓦洛兰特 #0%抽水 #3天交付`

### 3–12s · 今日焦点 6（行式化+去重）
- **操作**：Hero 下滚至 `⭐ 今日焦点`，鼠标横扫 6 卡（3 列×2 行），悬停 1 卡出现青绿边
- **对准**：`今日焦点` 6 张、去重无重复队名、`LIVE` 左 3px 竖条、`tournament-chip` + 黄胶囊同行不换行
- **口播**（9s）：“今日焦点 6 场，行式化扫视，3列2行无孤卡——这就是小赛事主办要的密度。”
- **要点**：若焦点不足 6 则解释“合并 hot+live 去重取 6，空时整区隐藏”

### 12–25s · 赔率胶囊 + 地图比分 → 点进详情
- **操作**：在焦点 6 中点任意一卡 → `MatchDetail`
- **对准**：
  - 卡片右上角 `1.85 / 2.10` 黄胶囊（`match-odds-capsule`，`#FFB547 10% 底`）
  - 已结束卡底部 `map-chips`（如 `Haven 13-4` `Bind 13-7`），胜者高亮
  - 进入详情后：彩池赔率实时、押注滑块、票型列表
- **口播**（13s）：“赔率不是写死的——总彩池除单边，0%抽水；地图比分条像 HLTV，一眼看赛果。”
- **字幕**：`赔率 = 总池/单边 · 0%抽水`

### 25–40s · 排行榜 Level 徽章 + ELO 进度
- **操作**：切至 `/leaderboard`，先 Podium 3 再下拉表格；若已实现 Level 徽章则特写 `Lv7` / `Lv10` 色阶
- **对准**：
  - 领奖台金银铜 + `LvX` 徽章（灰→绿→蓝→橙→红）
  - 表格 `ELO` 窄列 3px 进度条（绿→青），`points=0` 进度 0
  - 切换 `积分榜 / 胜率榜 / 亏损榜` 时 Level 仍按 `points` 算
- **口播**（15s）：“榜单不止积分——Level 徽章与 ELO 进度，纯前端计算，不动后端排名。甲方一眼看出活跃度分层。”
- **兜底**：若当前分支 Level 尚未上线，口播改为“纯积分排行，胜率与连胜辅助列，0 积分可兜底冲榜”

### 40–55s · 案例墙 + 定价（转化页）
- **操作**：`/showcase` → `/pricing`
- **对准**：
  - Showcase：顶部 `已交付 32 场瓦洛兰特演示赛 · 0%抽水纯彩池 · 3天可交付同款`（与 Hero 对齐）+ 6 宫格 `score/time/desc` 三行完整 + 底部 CTA
  - Pricing：`复刻 8000起` / `单场 800-2000/场` 两档卡 + `定金 4:5:1` 三步 + `3天交付` 小字；CTA `mailto:contact@example.com` 与 `/login`
- **口播**（15s）：“32 场已交付可验，6 宫格渐变占位零 404；定价两档——复刻 8000 起，单场 800 到 2000，定金 4:5:1，三天交付。”
- **字幕**：`复刻 8000起 · 单场 800-2000 · 4:5:1 · 3天交付`

### 55–60s · demo_player 登录押注一笔
- **操作**：`/login` 输入 `demo_player / demo123` → 进入任意 `未开始` 场次 → 滑 100 积分押 A 队 → 评论区发“看好让一追二”
- **对准**：登录态头像、押注成功 toast、彩池赔率微调、评论实时冒泡
- **口播**（5s）：“想办同款？先用 demo_player 体验全流程，再谈定制。”
- **结束帧**：定格在押注成功页 1s，叠水印 `eggesports.com · 3天可交付同款`

## 录制前 Checklist（5 项）

1. `POST /api/seed/demo` 已灌（`demo_admin` 登录后执行），`/` 三区非空：焦点 6 + 赛程 6 + Podium 3
2. `GET /match/hot?gameId=1&limit=6` 与 `GET /leaderboard/top/3` 均 200 且 `teamA != teamB`
3. `1280 / 768 / 375` 三断点无横向溢出、`375px` 黄胶囊不换行（`font 10px + max-width 90`）
4. 录屏前清缓存/关插件，`fixLogoUrl` 无 Mixed Content 控制台 0 报错
5. 口播稿打印 1 份，60s 计时器就位，超时则压缩 Showcase 至 10s
