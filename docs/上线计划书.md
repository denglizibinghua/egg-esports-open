# Egg 赛事竞猜 — 上线计划书

> 当前状态：MVP Demo（核心链路跑通）  
> 目标：可对外使用、体验完整的电竞赛事竞猜平台

---

## 一、现状盘点

| 模块 | 做了什么 | 还缺什么 |
|---|---|---|
| 用户系统 | 注册/登录/JWT/BCrypt | 头像上传、密码修改、邮箱绑定 |
| 赛事管理 | 后台录入/编辑/删除 | 无赛程来源，全手动 |
| 押注系统 | 选边下注、防重复押 | 赔率系统、限时押注 |
| 结算系统 | 手动结算、自动清算 | 无自动结算、无争议处理 |
| 排行榜 | 积分排行/猜中率 | 周榜/月榜、成就徽章 |
| 前端 | Vue 2 + Element UI 暗黑风 | 移动端未适配、无 i18n |
| 安全 | JWT + BCrypt | 无登录限制、无操作日志 |

## 二、分阶段规划

### 阶段 1：补齐基础（2-3 周）

#### 1.1 前端完善
- [ ] 用户注册时加昵称校验（不能重复）
- [ ] 个人中心：修改密码、修改昵称
- [ ] 赛事卡片增加「已押注」标记，一眼看出押了哪场
- [ ] 押注后弹出确认提示 + 结果动画（猜中/猜错效果）
- [ ] 排行榜增加「我的排名」高亮（不在前 20 也能看到自己）
- [ ] 赛事列表空状态：「暂无赛事，等待管理员录入」

#### 1.2 后端加固
- [ ] 登录失败次数限制（5 次锁定 15 分钟）
- [ ] 押注接口幂等性保证（防止重复提交）
- [ ] 比赛开始后禁止押注（当前只判断已结束）
- [ ] 管理员操作日志：谁在什么时间创建/编辑/结算了哪场比赛
- [ ] 全局接口限流（防止刷分）

#### 1.3 数据初始化
- [ ] 录入 VCT CN 联赛当前赛季全部队伍和赛程
- [ ] 准备一批历史比赛数据用于测试排行榜
- [ ] 写一个 SQL 脚本批量导入，不用手动一条条录

---

### 阶段 2：玩法升级（3-4 周）

#### 2.1 多游戏支持
- [ ] 管理后台增加「游戏管理」页面
- [ ] 赛事列表顶部加游戏切换 Tab（瓦/CS2/Dota2/LOL）
- [ ] 每种游戏独立排行榜

#### 2.2 竞猜玩法
- [ ] **BO3/BO5 支持**：单场比赛拆成多局，每局独立押
- [ ] **特殊竞猜**：首杀队伍、总回合数、MVP 选手
- [ ] **竞猜房间**：创建私密房间，邀请好友对战猜中率
- [ ] **赔率系统**：根据两边押注人数动态调整赔率

#### 2.3 社交元素
- [ ] 赛事评论区（简单版：每场比赛一个讨论区）
- [ ] 用户主页：展示历史战绩、连胜记录、偏好队伍
- [ ] 关注系统：关注好友，看他们押了什么
- [ ] 押注分享：生成战绩卡片图片，一键分享

---

### 阶段 3：体验打磨（2-3 周）

#### 3.1 实时体验

- [ ] 押注截止倒计时（比赛开始前 5 分钟截止）

#### 3.2 移动端适配
- [ ] 响应式布局改造（flex + 媒体查询）

#### 3.3 数据可视化

## 三、技术债清单

| 债务 | 影响 | 建议 |
|---|---|---|
| Vue 2 停更 | Element UI 不再维护 | 阶段 2~3 考虑迁移 Vue 3 + Element Plus |
| 单体架构 | 后续扩展受限 | 日活 < 1000 之前不用动 |
| 无缓存 | 排行榜每次查库 | Redis 缓存 Top 100，5 分钟刷新 |
| 无测试 | 改代码靠人工验证 | 核心结算逻辑加单元测试 |
| 管理员靠改数据库 | 不安全 | 加管理员邀请码/后台创建功能 |
